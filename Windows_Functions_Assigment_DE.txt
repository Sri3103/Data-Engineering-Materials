1) Display all employee details and assign a unique row number based on salary in descending order.

select  *,row_number() over (order by salary desc) as Salary_List from employee;


2) Display employee names, salaries, and their salary ranks from highest to lowest. Employees with the same salary should receive the same rank. 

select empname, salary ,rank() over (order by salary desc  ) as salary_rank from employee ;


3) Rank all employees based on salary in descending order. Employees with the same salary should receive the same rank, without gaps in the ranking. 

select empname, salary ,dense_rank() over (order by salary desc  ) as salary_rank from employee ;


4) Assign row numbers to employees separately within each department, ordering employees by salary from highest to lowest. 

select empname, salary ,row_number() over (partition by DeptID order by salary desc ) as salary_rank from employee ;


5) Rank employees by salary within each department. Employees earning the same salary in the same department should receive the same rank. 

select empname, salary, dense_rank() over(partition by deptID order by salary desc) as emp_rank from employee;


6) Use a CTE to find employees whose salary dense rank is 2 or less within their department. Include ties.

with CTE 
select empname , dense_rank() over(partition by deptid order by salary) as salary_rk from employee where salary_rk <=2;
